# Process Log

Esta pasta reúne a documentação completa do processo de construção do Challenge 001.

## Arquivos

- `PROCESS_LOG.pdf` — versão principal para avaliação, exportada do Notion.
- `Process_Log.zip` — versão de apoio contendo o arquivo em Markdown e as imagens separadas utilizadas na documentação.

O PDF é a leitura principal. O ZIP preserva os arquivos-fonte da documentação para consulta e auditoria. A contagem consolidada de iterações está no **README principal da submissão**, na seção `Process Log — Como usei IA`.
