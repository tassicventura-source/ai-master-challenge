# Percurso executivo

1. Abra **Visão executiva** para entender o tamanho dos eventos, reembolsos e crescimento.
2. Siga para **Finance e RevOps** e filtre o contexto pago ou os eventos com reembolso.
3. Selecione uma conta e clique em **Abrir Conta 360**.
4. Confira os registros cronológicos e inclua produto/atendimento quando necessário. Exporte o recorte para a pessoa responsável.

A jornada é reconstruída a partir dos registros observados, mas o resultado econômico continua pendente de conciliação. O sistema não atribui causa ao churn nem sugere que os campos futuros já estejam preenchidos.

A operação proposta continua nos sistemas atuais: cada área registra campos consistentes e compartilha as mesmas chaves. Este MVP demonstra a estrutura e o percurso de investigação; integrações operacionais e automações são etapas futuras.
